## Brand & Style
The design system establishes a premium, scientific "cyber-marine" environmental IoT aesthetic. It merges high-reliability industrial monitoring with the elegance of deep-ocean bioluminescence. The interface communicates surgical precision, situational command, and absolute environmental stewardship.

### Visual Style
- **Aesthetic Direction**: Deep Abyss Glassmorphism & Cyber-Marine Precision.
- **Atmosphere**: Deep, optical-density water layers punctuated by bioluminescent light sources.
- **Mood**: High-fidelity, authoritative, calm, futuristic yet deeply utilitarian. High contrast is preserved at every level to maintain situational awareness in industrial operations centers and field sunlight conditions.

## Colors
The color palette uses a disciplined dark palette derived from oceanic depths, accented by photon-charged signals.

### Surface Tiers
- **Void Surface (App Canvas)**: `#08111F` — Absolute base level mimicking deep abyssal trenches.
- **Layer 1 Surface (Containers/Cards)**: `#0D1929` — Mid-depth container base with 70–85% opacity when paired with blur filters.
- **Layer 2 Surface (Elevated Panels/Flyouts)**: `#111F30` — Top-tier interactive panels, inspect sheets, and hovering telemetry panels.
- **Surface Borders**: `rgba(56, 189, 248, 0.12)` to `rgba(20, 184, 166, 0.2)` — Crisp structural bounds mimicking precision instrumentation glass.

### Signal & Data Accents
- **Primary (Bioluminescent Teal)**: `#14B8A6` — Core interactions, active device heartbeats, and primary data traces.
- **Secondary (Hydro Cyan)**: `#38BDF8` — Secondary metrics, water flow indicators, sub-navigation, and informational triggers.
- **Tertiary (Deep Indigo/Spectral)**: `#818CF8` — Ancillary sensor metadata, bathymetric depth charts, and system analytics.

### Telemetry Status Tokens
- **Operational Nominal (Success)**: `#22C55E` — Steady-state water chemistry, dissolved oxygen within bounds.
- **Threshold Advisory (Warning)**: `#F59E0B` — Turbidity shifts, battery voltage depletion, moderate algae blooms.
- **Critical Deviation (Alert)**: `#EF4444` — Contamination surges, offline telemetry gateways, severe hypoxic events.

### Typography & Content Tone
- **Primary Text**: `#F8FAFC` — High legibility readout values, prominent titles, active metric counters.
- **Muted Text**: `#94A3B8` — Engineering units (e.g., `mg/L`, `NTU`, `pH`), timestamps, coordinate grid metadata.
- **Ghost Text**: `#475569` — De-emphasized structural hints, axis divisions, and inactive slot markers.

## Typography
The system utilizes a dual-font architectural strategy:

1. **Inter**: Governs UI scaffolding, structural headings, narrative descriptions, and control interfaces. Font features like tabular figures (`tnum`) should be toggled on universally for tabular lists.
2. **JetBrains Mono**: Dedicated to the instrumentation plane: raw sensor arrays, scientific units, GPS telemetry, timestamps, and live numerical indicators.

### Readout Treatment
Metric numbers must render in tabular monospace figures to avoid layout shift during high-frequency real-time socket updates (e.g., streaming water flow, temperature micro-oscillations). All uppercase micro-labels utilize tracking between `+0.04em` and `+0.06em` to maintain legibility against dark translucent grounds.

## Layout & Spacing
A fluid 12-column engineering grid tailored for dense data display and operations dashboards.

### Grid & Breakpoints
- **Mobile (<768px)**: 4 columns, `margin: 1rem` (`16px`), `gutter: 1rem` (`16px`). Dashboard widgets stack vertically into modular cards.
- **Tablet (768px–1199px)**: 8 columns, `margin-md: 1.5rem` (`24px`), `gutter: 1rem` (`16px`). Split-view: Telemetry summaries on top, map/chart splits below.
- **Desktop (≥1200px)**: 12 columns, `margin-lg: 2.5rem` (`40px`), `gutter-lg: 1.5rem` (`24px`). Persistent geospatial bathymetry/lake model canvas with floating precision telemetry sidebars.

### Rhythm
Components follow a strict 4px base increment. Data matrices prioritize horizontal space economy to display comparative sensor streams without horizontal scrolling.

## Elevation & Depth
Depth mimics light passing through varied water layers, replacing traditional opaque shadows with illuminated volumetric edges and translucent frosted tiers.

### Layer Tiers
- **Tier 0 (Sub-Surface Base)**: Solid `#08111F`. Static backdrop for GIS lake maps and telemetry coordinate systems.
- **Tier 1 (Submerged Containers)**: Background `rgba(13, 25, 41, 0.75)`, backdrop blur `12px`, border `1px solid rgba(56, 189, 248, 0.08)`. No cast shadow.
- **Tier 2 (Active Gauges & Instruments)**: Background `rgba(17, 31, 48, 0.85)`, backdrop blur `16px`, border `1px solid rgba(20, 184, 166, 0.25)`, drop-shadow `0 8px 32px -4px rgba(0, 0, 0, 0.60)`.
- **Tier 3 (Floating Command Palettes / Overlays)**: Background `rgba(17, 31, 48, 0.95)`, backdrop blur `24px`, border `1px solid rgba(56, 189, 248, 0.35)`, drop-shadow `0 16px 48px -8px rgba(0, 0, 0, 0.80)`.

### Bioluminescent Glow
Active actuators and critical status states project colored optical glows:
- **Teal Active Halo**: `box-shadow: 0 0 16px rgba(20, 184, 166, 0.35)`
- **Cyan Signal Pulse**: `box-shadow: 0 0 16px rgba(56, 189, 248, 0.35)`
- **Alert Beacon**: `box-shadow: 0 0 20px rgba(239, 68, 68, 0.45)`

## Shapes
A disciplined "Soft" curvature philosophy (`roundedness: 1`). Instrumentation hardware demands structural rigidity, eschewing oversized circular geometries in favor of technical, compact forms.

- **Base Radius (`space-xs` = 4px)**: Buttons, inputs, inline status chips, data tags.
- **Container Radius (`rounded-lg` = 8px)**: Telemetry widgets, chart enclosures, modal dialogs, data table wrappers.
- **Card Radius (`rounded-xl` = 12px)**: Primary application dock, main operational viewports, GIS map floating frames.
- **Full Pill (`9999px`)**: Exclusively reserved for live transmission status indicators and numeric gauge dial endpoints.

## Components

### Buttons & Actuators
- **Primary (Tactile Ignition)**: High-luminance teal background (`#14B8A6`), text `#08111F` (ultra-dark navy for accessible contrast), font-weight 600. Subtle top-edge inner highlight (`inset 0 1px 0 rgba(255, 255, 255, 0.3)`). Hover: `#0D9488` with a soft teal aura.
- **Secondary (Telemetry Control)**: Transparent background with `1px solid rgba(56, 189, 248, 0.3)`, text `#F8FAFC`. Hover: `background: rgba(56, 189, 248, 0.08)`, border-color `#38BDF8`.
- **Destructive/Emergency**: Red outline (`rgba(239, 68, 68, 0.4)`), text `#EF4444`. Active click engages solid `#EF4444` fill with white text.

### Telemetry Badges & Chips
- Compact, monospaced data indicators.
- **Structure**: Leading 6px pulsing dot (indicating ping/connection), label in `label-sm` uppercase, and tabular reading.
- **Live Stream Pill**: Background `rgba(20, 184, 166, 0.12)`, border `1px solid rgba(20, 184, 166, 0.3)`, text `#14B8A6`.

### Cards & Telemetry Modules
- Backed by Layer 1 glassmorphism (`rgba(13, 25, 41, 0.8)`).
- Top header section housing widget title, node serial identifier (`JetBrains Mono`, `#94A3B8`), and sync freshness timestamp (`e.g., 1.2s ago`).
- Dividers between sections use ultra-thin lines (`1px solid rgba(148, 163, 184, 0.08)`).

### Input Fields & Selectors
- Background `rgba(8, 17, 31, 0.8)` inset within cards.
- Border: `1px solid rgba(148, 163, 184, 0.2)`. Focus: border switches to `#14B8A6` with an outer ring of `0 0 0 2px rgba(20, 184, 166, 0.25)`. Text `#F8FAFC`.
- Integrated engineering units (`pH`, `μS/cm`, `m³/s`) pinned rightwards in `#94A3B8`.

### Checkboxes & Switches
- **Toggle Switches**: Recessed track `#08111F` with a `1px` border; active slider head snaps into place glowing with `#14B8A6`.
- **Checkboxes**: Crisp 4px radius box. Checked state features a teal fill with dark checkmark icon.

### Data Charts & Scientific Gauges
- **Sparklines & Charts**: Area fills with vertical opacity gradients fading from `30%` accent color down to `0%` near the base.
- **Grid Lines**: Dotted or hairline strokes in `rgba(148, 163, 184, 0.1)`.
- **Crosshair / Tooltips**: Opaque floating capsule (`#111F30`), crisp `#38BDF8` border line, and precise multi-sensor readouts aligned in tabular columns.
